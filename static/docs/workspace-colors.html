Workspace colors

Open Dashboard → Account → Workspace colors (Settings → Account for administrators). Choose a profile, inspect its read-only Python preview, and select Save editor colors. The profile supplies matching tones for editors, Files, Shell, and Resources. Preferences save to your account.

The custom background control changes editors only. Use scheme background removes that override. Dark and light overrides are saved separately; an existing override remains when switching between profiles of the same mode. Use the reset button to see a new profile's intended background. Follow page theme selects Eagle Dark or Eagle Light; explicit profiles keep their appearance when the page theme changes.

Readability and member colors

Syntax text is adjusted to at least 4.5:1 contrast against its editor background, including custom backgrounds. Workspace text, muted labels, accents, and status colors are checked against the profile's panel, input, popup, and file-hover surfaces. Home prose and rendered Markdown follow the profile independently of the page theme. Error, warning, and success labels keep their meanings in every palette.

Current profiles progressively darken member accents through four levels; Eagle Dark uses green. For example, self.elements[element2].atomic_mass keeps the second member level after the index. Balanced call arguments and quoted keys are skipped when counting receiver depth. This is bounded local syntax styling, not type inference; it never executes code. Legacy Dark/Light preserve September's Monokai/default token categories with readable contrast and omit the additional member styles.

Inspiration

These adapted palettes were inspired by the Omarchy theme gallery: Amberbyte, Aura, Ayaka, Demon, Gold Rush, Green Garden, Harbor, RetroPC, Evergarden, Lamplight, and Flexoki Dark. The profiles use EagleIDE's own token roles and contrast adjustments; no wallpapers, fonts, or OS settings are installed.
